#  JPMorgan Chase & Co. Financial Data Analysis

This project analyzes and forecasts the stock price of **JPMorgan Chase (JPM)** using Python. It includes data preprocessing, visual exploration, technical indicators, and a basic machine learning model for prediction.

---

## 🔍 Features

-  **Data Handling**
  - Load and clean historical stock data from CSV.
  
-  **Data Visualization**
  - Closing price trends over time.
  - Daily returns and volatility.
  - Correlation heatmap.
  - Monthly average returns.

-  **Technical Indicators**
  - RSI (Relative Strength Index).
  - MACD (Moving Average Convergence Divergence).
  - SMA 50 & 200 (Simple Moving Averages).

-  **Forecasting**
  - Linear Regression model for predicting future closing prices.
  - Comparison plot of actual vs predicted values.
